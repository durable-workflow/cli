Durable Workflow CLI 2.5.0-rc.3 (release candidate)

**This is not a usable release for everyday use. Do not install it outside
testing.** It is the first feature-complete build of the CLI's Rust
implementation, published to verify the installed binaries before 2.5.0.
Keep using the latest stable release, 2.3.6, for real work.

Every 2.x command is implemented: all 86 commands, with the same names,
options, JSON shapes and exit codes as 2.x. A parity suite compares this
build with the published 2.3.5 CLI case by case, offline and against
published PHP Server 2.11.8 and native Server 3.0.5. Intentional
differences are listed in the 2.5.0 notes (`docs/release-notes/2.5.0.md`).

This prerelease is never selected automatically:

- `install.sh`, `install.ps1` and `dw upgrade` without `--tag` install the
  latest stable release, which stays 2.3.6.
- The Homebrew formula in this release is not published to any tap.

To try it, upgrade a 2.x binary install explicitly with
`dw upgrade --tag 2.5.0-rc.3`, or download and verify a binary as described
in the 2.5.0 notes.

What the release run checks: the Rust release workflow builds, attests and
publishes binaries for Linux (x86_64, aarch64; statically linked), macOS
(Apple Silicon, Intel) and Windows, plus `SHA256SUMS`, the installers,
`verify-release.sh` and `dw.rb`. After publication it verifies every download
and attestation, upgrades published 2.x binary installs to this release with
`dw upgrade --tag 2.5.0-rc.3`, and checks that a 2.x PHAR install resolves
this release's binary and checksum before refusing, as 2.x always does for a
PHAR.

GitHub releases in this repository are immutable: this prerelease's assets
and tag are locked and can't be changed or removed, and the tag name
`2.5.0-rc.3` can't be reused.
