Durable Workflow CLI 2.5.1

## Intel Macs can use the installer

`install.sh` now installs `dw-macos-x86_64` on Intel Macs. In 2.5.0 it still
refused them with "Use the PHAR with a system PHP instead", although 2.5.0
publishes the Intel binary and no PHAR (cli#135).

```bash
curl -fsSL https://github.com/durable-workflow/cli/releases/latest/download/install.sh | sh
```

Pinning an Intel Mac to a release before 2.5.0 (`VERSION=2.3.6`) is refused
with a message, because those releases have no Intel macOS binary.

The `dw` binaries are otherwise unchanged from 2.5.0. See the
[2.5.0 notes](2.5.0.md) for the move to the Rust implementation, moving off
`dw.phar`, and the intentional differences from 2.x. The 2.3.x PHAR line
receives security fixes only until 2027-02-28.
