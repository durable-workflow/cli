Durable Workflow CLI 2.5.0-rc.1 (pipeline validation preview)

**This is not a usable release. Do not install it.** It exists only to check
the new release pipeline end to end before 2.5.0. Keep using 2.3.5.

2.5.0-rc.1 is the first build of the CLI's Rust implementation. Most commands
are not implemented yet: `workflow:*`, `schedule:*`, `namespace:*`,
`activity:*`, `worker:*` and the rest answer "not available in this dw build
yet". Only `env:*`, `server:health`, `server:info`, `help`, `list` and
`upgrade` work. Stable 2.5.0 waits until every command matches 2.x.

This prerelease is never selected automatically:

- `install.sh`, `install.ps1` and `dw upgrade` without `--tag` install the
  latest stable release, which stays 2.3.5.
- The Homebrew formula in this release is not published to any tap.

What it checks: the Rust release workflow builds, attests and publishes
static binaries for Linux (x86_64, aarch64), macOS (Apple Silicon, Intel) and
Windows, plus `SHA256SUMS`, the installers, `verify-release.sh` and `dw.rb`.
After publication it verifies every download and attestation, and upgrades
published 2.3.5 binary and PHAR installs to this release with
`dw upgrade --tag 2.5.0-rc.1` on Linux x86_64, Linux aarch64 and macOS arm64.

GitHub releases in this repository are immutable: this prerelease and its
assets can't be edited or deleted, and its tag can't be reused.
