Durable Workflow CLI 2.5.0-rc.2 (pipeline validation preview)

**This is not a usable release. Do not install it.** It exists only to check
the new release pipeline end to end before 2.5.0. Keep using 2.3.5.

2.5.0-rc.2 is a build of the CLI's Rust implementation. Most commands
are not implemented yet: `workflow:*`, `schedule:*`, `namespace:*`,
`activity:*`, `worker:*` and the rest answer "not available in this dw build
yet". Only `env:*`, `server:health`, `server:info`, `help`, `list` and
`upgrade` work. Stable 2.5.0 waits until every command matches 2.x.

This prerelease is never selected automatically:

- `install.sh`, `install.ps1` and `dw upgrade` without `--tag` install the
  latest stable release, which stays 2.3.5.
- The Homebrew formula in this release is not published to any tap.

What it checks: the Rust release workflow builds, attests and publishes
binaries for Linux (x86_64, aarch64; statically linked), macOS (Apple
Silicon, Intel) and Windows, plus `SHA256SUMS`, the installers,
`verify-release.sh` and `dw.rb`. After publication it verifies every download
and attestation. On Linux x86_64, Linux aarch64 and macOS arm64 it upgrades a
published 2.3.5 binary install to this release with
`dw upgrade --tag 2.5.0-rc.2`, and checks that a 2.3.5 PHAR install resolves
this release's binary and checksum before refusing, as 2.x always does for a
PHAR.

GitHub releases in this repository are immutable: this prerelease's assets
and tag are locked and can't be changed or removed, and the tag name
`2.5.0-rc.2` can't be reused.

2.5.0-rc.2 repeats 2.5.0-rc.1's run. rc.1's artifacts verified, but one
automated post-release check stopped early on a workflow defect (its
installer test did not put the install directory on `PATH`), since fixed.
